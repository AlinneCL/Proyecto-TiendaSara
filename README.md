# Proyecto Tienda Sara – Actividad 2

Incluye index.html (inicio), productos.html (galería), carrito.html (carrito), styles.css y app.js.

Abre la carpeta en Visual Studio Code y ejecuta index.html en un navegador. Bootstrap se carga por CDN; requiere internet. Es un prototipo académico: no se conecta a SQL Server ni procesa pagos reales.
